# Ruby技術者認定試験 学習アプリ

Ruby技術者認定試験（Silver / Gold）の学習を支援するためのWebアプリです。

一般的な問題演習に加えて、**手が使えないタイミングでも学習できること**を目指しています。

たとえば、家事や身支度などをしながらでも学習を続けられるように、

* 問題を表示
* 一定時間後に選択肢を表示
* さらに一定時間後に正解・解説を表示
* 次の問題へ自動で移動

といった、問題の**自動送り機能**を実装する予定です。

## 主な機能

現在は、まず基本的な問題演習機能の実装を進めています。

* Ruby Silver / Gold の試験区分
* 問題の表示
* 選択肢の表示
* 正解・解説の表示
* 問題の自動送り機能

今後は、学習履歴や間違えた問題の再出題なども追加する予定です。

---

## このリポジトリのもうひとつの目的

このアプリはサービス開発だけでなく、**PHP / Laravelの学習用プロジェクト**としても作成しています。

Ruby / Ruby on RailsでのWebアプリ開発経験をベースに、PHP / Laravelとの違いを意識しながら実装を進めています。

また、AIを単純にコード生成に利用するのではなく、

* 実装方針をAIと相談する
* 生成されたコードの内容を理解する
* 設計や実装について自分で判断する
* 必要に応じてAIへ修正を依頼する

といった流れを通して、**AIを活用した開発（バイブコーディング）に慣れること**も目的としています。
